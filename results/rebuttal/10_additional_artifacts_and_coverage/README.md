# 10_additional_artifacts_and_coverage

Supplemental experimental artifacts, including superseded pilots, connectivity probes, semantic development outputs and configuration diagnostics. They retain their original status and must not be substituted for final results.

source_inventory.json maps every scoped input to a hash-identical existing archived file/member or a new member. Restore split bundles with ../restore_evidence.py. Only new distinct contents are stored; repeated contents retain all source mappings. Raw experiments are unchanged.
