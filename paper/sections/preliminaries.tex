\section{Preliminaries}\label{sec:preliminaries}
%% ============================================================

\paragraph{Loop verification.}
A task consists of a loop \(\mathcal L=(P,B,S)\) and a target set
\(Q=\{(\ell,q_\ell)\}\), where predicate \(q_\ell\) occurs at assertion or
postcondition location \(\ell\).  Here \(P\) is the loop-entry predicate induced by the function
preconditions and executable prefix, \(B\) is the guard, and \(S\) is the
body.  Let
\(\operatorname{Reach}(\mathcal L)\) be the reachable loop-head states,
including the final guard test.  Throughout this paper, we use \emph{valid}
as a term of art for \emph{inductive under the following proof obligations}:
\[
  P\Rightarrow I,
  \qquad
  \{I\wedge B\}\,S\,\{I\},
\]
which ensures \(\operatorname{Reach}(\mathcal L)\subseteq\denote I\)
~\citep{floyd1967assigning,hoare1969axiomatic}.  The semantic ideal---an
invariant whose meaning is exactly \(\operatorname{Reach}(\mathcal L)\)---need
not be finitely expressible in the annotation language.  This convention is
narrower than merely requiring a predicate to hold on every reachable state:
such a semantically true predicate need not be provable from these particular
induction obligations or by the resource-bounded verifier used below.

For predicates \(I\) and \(J\), write
\[
  I\preceq J
  \quad\Longleftrightarrow\quad
  I\Rightarrow J
  \quad\Longleftrightarrow\quad
  \denote I\subseteq\denote J.
\]
Thus \(I\preceq J\) means that \(I\) is at least as strong as \(J\), and
\(I\prec J\) means that it is strictly stronger.  For a finite clause set
\(C\), define
\[
  I_C\triangleq\bigwedge_{c\in C}c,
  \qquad I_\varnothing\triangleq\mathit{true}.
\]
We call \(C\) \emph{jointly inductive} when \(I_C\) is valid, equivalently
when
\[
  P\Rightarrow I_C,
  \qquad
  \{I_C\wedge B\}\,S\,\{I_C\}.
\]
We reserve \(\mathsf H_{\mathcal L}(C)\) for the ideal Houdini fixed point
under exact establishment and preservation decisions, and
\(\mathsf{Filter}_{\mathcal L}(C)\) for the implemented parsing,
deduplication, and resource-bounded WP/Houdini pipeline.

A valid invariant is
\emph{\(Q\)-sufficient} when annotating the loop with \(I\) lets the verifier
prove every \(q_\ell\) at \(\ell\).  More explicitly, let \(S_{<\ell}\) be
the loop-body prefix on a control-flow path leading to an assertion at
location \(\ell\).  The restored target obligations include
\[
  \begin{aligned}
  &\{I\wedge B\}\,S_{<\ell}\,\{q_\ell\}
    &&\text{for every feasible path to an in-body assertion},\\
  &I\wedge\neg B\Rightarrow q_\ell
    &&\text{for a post-loop target}.
  \end{aligned}
\]
Function postconditions and assertions outside the loop analogously use the
standard path condition propagated from the loop exit to \(\ell\).  We write
\(\operatorname{Verify}(\mathcal L,I,Q)\) for the conjunction of
establishment, preservation, and all of these location-specific obligations.
Thus validity is target-independent, whereas sufficiency is tested only after
restoring \(Q\).

\paragraph{Target-hidden verification.}
The generator and all intermediate scores use \(\mathcal L=(P,B,S)\), not
\(Q\).  Assertions, postconditions, executable assertion calls, and
conventional error-label names are masked; non-contract comments are removed.  Preconditions and executable loop
semantics remain visible.  The generated invariant is fixed before the
untouched program is restored for final verification.  We study scalar-integer
C programs with one loop; Appendix~\ref{app:scope-example} gives the scope and
a motivating nonlinear example.
