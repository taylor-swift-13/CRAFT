# RQ1: main verification results

This directory supports the comparison of compositional inference and aligned
training across local and API models.

- Model-named directories contain saved response pools and evaluation outputs.
- `paper_summaries/experiment_results_current.json` is the canonical source
  for the main table and training-stage plots.
- `paper_summaries/pass_count_projection.json` records displayed pass-rate
  projections.
- `paper_summaries/grid_summaries/` contains compact API-model summaries.
