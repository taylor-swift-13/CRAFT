## LOOP INVARIANT DEFINITION

A loop invariant is a property that:
1. Holds before the first loop iteration (initialization).
2. Is preserved by every loop iteration when the loop guard is true (inductiveness).
3. Combined with loop exit (`!guard`), helps establish required loop-exit facts.

## AVAILABLE LOGIC FUNCTIONS

You may use these pre-declared ACSL logic functions without defining them:

- `power(b, e)` — integer exponentiation, returns b multiplied by itself e times (`logic integer power(integer b, integer e) = e <= 0 ? 1 : b * power(b, e-1)`).
- `factorial(n)` — integer factorial, returns `1*2*...*n` (`logic integer factorial(integer n) = n <= 0 ? 1 : n * factorial(n-1)`).

Use `power(base, exp)` instead of writing `base*base*...*base`, and `factorial(n)` instead of writing `1*2*3*...*n` or inventing axioms/axiomatics.

- Add minimal progress bounds for loop counters and key arithmetic variables.
- Prefer strong invariants; avoid weak/tautological ones.
