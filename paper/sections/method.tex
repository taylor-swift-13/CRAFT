\subsection{Rollout--Combine--Filter}
\label{sec:method:core}

For a target-masked loop \(\mathcal L\), the model emits ACSL loop-invariant
annotations~\citep{acsl}.  Parsing extracts each
\texttt{loop invariant ...;} annotation as one clause; normalization turns
response \(i\) into
\(A_i=(a_{i1},\ldots,a_{im_i})\).  We cap it at \(K\) clauses,
\(\bar A_i=(a_{i1},\ldots,a_{i,\min(m_i,K)})\), with overflow
\(o(A_i)=\max(0,m_i-K)\).  Extraction makes the annotation, rather than the complete
response, the unit that can survive filtering and earn credit.

Given \(G\) responses, RCF unions their clauses,
\[
  X_0=\bigcup_{i=1}^{G}\bar A_i,
\]
then iteratively removes syntax failures and applies Houdini to delete clauses
whose establishment or preservation obligations fail
~\citep{flanagan2001houdini}.  We write the resulting inductive subset as
\(\mathsf{Filter}_{\mathcal L}(X_0)\).  Conjoining valid clauses preserves
validity and can combine a bound from one response with a relation from
another; filtering salvages such clauses from otherwise imperfect responses
but cannot invent a missing relation.  Algorithm~\ref{alg:rcf} is shared by
SFT synthesis and deployment.

\begin{algorithm}[t]
\caption{Rollout--combine--filter}
\label{alg:rcf}
\begin{algorithmic}
\alginput{masked loop \(\mathcal L\), parsed clause sequences \(A_{1:G}\), cap \(K\)}
\algoutput{filtered clause set \(C\)}
\algline \(C\leftarrow\bigcup_i
  \operatorname{Cap}_K(\operatorname{Normalize}(A_i))\)\\
\algline \(C\leftarrow\operatorname{ConservativeDedup}(C)\)\\
\algline \kw{repeat}\\
\algline \algind \(E\leftarrow\operatorname{ParserErrors}(\mathcal L,C)\); \(C\leftarrow C\setminus E\)\\
\algline \kw{until} \(E=\varnothing\) or \(C=\varnothing\)\\
\algline \kw{repeat}\\
\algline \algind \(D\leftarrow\{c\in C:
  \neg\operatorname{WP}_{\rm est,pres}(\mathcal L,C,c)\}\);
  \(C\leftarrow C\setminus D\)\\
\algline \kw{until} \(D=\varnothing\) or \(C=\varnothing\)\\
\algline \kw{return} \(C\)\\
\end{algorithmic}
\end{algorithm}

RL scoring additionally removes clauses contradicted by observed reachable
states \(\mathcal P\) before Houdini:
\[
  \mathsf{PF}_{\mathcal P}(X)
  =\{a\in X:\forall p\in\mathcal P,\ p\models a\}.
\]
This positive filter is a cheap refutation step, not a validity proof;
Frama-C/WP remains the authority.  It is used only for RL scoring; deployment
performs the same identifier-scope checks but no execution-based rejection.
Appendix~\ref{app:constants} gives normalization and filtering details.

\subsection{Distilling Multi-Response Search}
\label{sec:method:sft}

For each masked loop \(\mathcal L\) in the training set \(\mathcal T\), let
\(X_0(\mathcal L)\) be a sampled response-group union and
\(C_{\mathcal L}=\mathsf{Filter}_{\mathcal L}(X_0(\mathcal L))\).  We
serialize every nonempty result as one SFT target:
\[
  \mathcal D_{\mathrm{SFT}}
  =\{(\mathcal L,\operatorname{serialize}(C_{\mathcal L})):
      \mathcal L\in\mathcal T,\ C_{\mathcal L}\neq\varnothing\}.
\]
Neither input nor target contains \(Q\): SFT serializes a Houdini-retained
multi-response search result as one response.  Execution states
are used only for RL rewards, never as SFT answers.

\subsection{Target-Independent Strength Examples}
\label{sec:method:sampler}

To grade inductive sets without \(Q\), we execute a deterministic,
precondition-checked input sweep and record reachable loop-head states
\(\mathcal P\).  From these executions we construct three negative-example
families: local one- or two-variable perturbations that break relations,
continuations of the real body after a witnessed loop exit, and perturbations
outside observed variable ranges.  Conservative cleaning removes observed
reachable states, possible fresh entries, duplicates, and candidates involving
unsupported state.  These examples are training signals, not proofs of global
unreachability; unsupported or incomplete executions disable the affected
family.  Figure~\ref{fig:negative-sampling}, Algorithm~\ref{alg:negative-sampling},
and exact budgets appear in Appendix~\ref{app:negative-sampling}.

Let \(\mathcal N\) be the retained negative traces.  For a retained clause set
\(X\), \(\mathrm{rej}(X)\subseteq\mathcal N\) contains each trace on which at
least one clause in \(X\) is false at some recorded state; singleton traces
recover ordinary state rejection.

\subsection{Clause-Decomposed, Group-Compositional Reward}
\label{sec:method:reward}

For rollout \(i\), define its verifier-retained subset and rejected negatives
as
\[
  S_i=\mathsf{Filter}_{\mathcal L}
  (\mathsf{PF}_{\mathcal P}(\bar A_i)),
  \qquad R_i=\mathrm{rej}(S_i).
\]
This projection implements \emph{intra-rollout decomposition}: malformed or
non-inductive clauses are removed without erasing useful clauses in the same
response.  When retained negatives exist, the reward adds no bonus merely for
valid syntax or whole-response validity.  The subset receives the dense,
target-independent strength score
\[
  \mathrm{coverage}(A_i)=\frac{|R_i|}{|\mathcal N|}.
\]
This and the following allocation apply when \(\mathcal N\neq\varnothing\);
when the sampler retains none, we use the binary fallback in
Appendix~\ref{app:grpo-details}.

Independent coverage, however, rewards a complementary discovery exactly like
one repeated by every peer.  We therefore allocate the union of the
standalone-retained rejection sets with the coverage game
\(v(T)=|\bigcup_{j\in T}R_j|/|\mathcal N|\).  Let
\(f(n)=\sum_{j=1}^{G}\mathbf 1[n\in R_j]\).  The Shapley value of rollout
\(i\) has the closed form~\citep{shapley1953value}
\begin{equation}
\label{eq:shapley-credit}
  \phi_i=\frac{1}{|\mathcal N|}
  \sum_{n\in R_i}\frac{1}{f(n)},
  \qquad
  \sum_{i=1}^{G}\phi_i
  =\frac{|\bigcup_iR_i|}{|\mathcal N|}.
\end{equation}
Thus a unique rejection receives full credit, whereas \(f(n)\) redundant
rejections split it.  This closed form uses already-computed rejection sets
and adds no verifier calls.  It implements \emph{inter-rollout composition}:
the same response earns less group credit when its verified constraints are
already supplied by peers.

With conservative within-response duplicate count
\(d_{\rm dup}(A_i)=|\bar A_i|-|\operatorname{dedup}(\bar A_i)|\), the reward is
\begin{equation}
\label{eq:generation-reward}
  r_i=w_c\,\mathrm{coverage}(A_i)+w_g\phi_i
      -w_d d_{\rm dup}(A_i)-w_o o(A_i),
\end{equation}
where \((w_c,w_g,w_d,w_o)=(1.0,0.3,0.02,0.05)\).  GRPO normalizes these
group-conditioned rewards within the sampled response group.  Shapley credit
distinguishes equal-coverage rollouts when their rejection sets overlap
differently, favoring less redundant coverage.  It remains a target-independent
behavioral surrogate rather than credit for final \(Q\)-sufficiency.
Appendix~\ref{app:grpo-details} gives the standard
policy objective, duplicate normalization, and fallback behavior.

\subsection{Deployment Objective}
\label{sec:method:inference}

At deployment, RCF samples \(k\) masked responses and produces
\[
  X_k=\bigcup_{i=1}^{k}\bar A_i,\qquad
  C_k=\mathsf{Filter}_{\mathcal L}(X_k),\qquad
  I_k=\bigwedge_{a\in C_k}a.
\]
Only then is \(Q\) restored.  The target utility and inference objective are
\[
  U_Q(A_{1:k})=\mathbf 1[\operatorname{Verify}(\mathcal L,I_k,Q)],
  \qquad
  \max_\pi\ \mathbb E_{A_{1:k}\sim\pi(\cdot\mid\mathcal L)}[U_Q(A_{1:k})].
\]
Here \(\operatorname{Verify}\) requires establishment, preservation, and every
restored target at its original location; for one post-loop target, its last
obligation is \(I_k\wedge\neg B\Rightarrow q\).
Its empirical counterpart is combine@\(k\), which can succeed even when no
standalone response is sufficient.  Training therefore aims to raise this
curve and reach its large-pool performance with fewer rollouts.
