# RQ2: tool comparison

This directory contains target-hidden comparisons with AutoSpec, SESpec,
Clause2Inv, Loopy, Daikon, and CRAFT.

- `gpt5nano_full832/` contains the consolidated tool evaluation.
- `gpt5nano_loris_no_reasoning_cap8192_partial/` preserves an incomplete
  25-event LORIS run, separate from the consolidated results.
- `autospec_strict_usage_v2/` contains the strict AutoSpec rerun.
- Other run directories preserve reasoning and serving variants.
- `paper_summaries/` contains the final audit, cost data, and compact grid
  summary used by the manuscript.
