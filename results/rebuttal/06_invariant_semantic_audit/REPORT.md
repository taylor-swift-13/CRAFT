# CRAFT@16：不变量强度与精确可达性审计

本分析复用 GPT-5-nano/minimal 新批次 @16 的最终 `survivors`，没有调用模型、重新训练或修改原实验结果。原验证成功数仍为 602/832。832 个源程序和 832 个验证记录的哈希均未改变。

|---|---:|---:|
| 严格强于隐藏目标的验证条件 | 403（48.44%） | 396（65.78%） |

这些是本次方法可确认的数量下界。两类性质不互斥：全部程序中有 234 个同时满足两者，原验证成功子集中有 229 个。

## exact 的严格定义

令 c 表示合法的函数入口与循环入口上下文，Reach(P,c) 表示从该上下文出发，经过零次或有限次合法循环迭代可到达的循环头状态集合。将最终保留子句的合取记为 I16，并将程序保留的入口、未修改变量和类型约束记为 K：

I_eff(s,c) = K(s,c) AND I16(s,c)。

精确可达性要求，对每个合法上下文 c：

{ s | I_eff(s,c) } = Reach(P,c)。

因此既不能漏掉任何可达状态，也不能包含不可达状态。仅仅归纳、足以证明目标，或者与目标等价，都不足以证明 exact。

本审计的结论针对显式建模的 32 位标量整数状态：有符号运算使用无未定义溢出的执行语义，无符号运算使用 32 位模运算；入口条件和程序未修改变量作为公共上下文保留。内存、浮点、未建模作用域、部分除法/移位、全局常量和含未初始化读取的程序保守列为未支持。不能将这些结果扩展为任意 C 程序语义下的完整判定。

## exact 如何证明

对每个 exact 正例，检查：

1. 所有合法初始循环头状态满足 I_eff。
2. 每次合法循环转移保持 I_eff。
3. 每个满足 I_eff 的非初始状态，都存在满足 I_eff 的合法前驱，且前驱在一个有界整数变量上严格更小（或在反向顺序上更小）。

第三项给出良基的反向可达性证明，保证每个 I_eff 状态都能回溯到合法初始状态；与前两项结合得到集合相等。它不是有限轨迹采样或仅检查归纳性。

非 exact 正例通过另一个已证明的归纳性质 L 和反例状态建立：该状态满足 I_eff 但违反 L，因此不可达。

共对 583 个有正面结论的程序重放了 3,050 个 SMT 查询。两个含量词的完整性查询重放超时，随后为 Loopy_50 和 linear_296 构造了显式前驱，并分别通过无量词检查和独立重放。最终无未解决的复核分歧。SMT 证书验证依赖分析器的语义翻译与 Z3；这不是 Rocq/CompCert 的端到端 C 语义认证。

## “严格强于目标”如何定义

不把循环头不变量与其他位置的断言直接作文本比较。先将隐藏断言经过相关路径和赋值折回循环头，得到目标验证条件 Q；对未来非确定性选择作全称解释。错误标签中的 assert(false) 转为对应路径不可发生的安全义务。

在共同入口、类型、未修改变量及适用路径上下文 C 下，要求：

- C AND I16 可满足，排除空前提。
- C AND I16 AND NOT Q 不可满足，即 I16 足以推出 Q。
- C AND Q AND NOT I16 可满足，即 Q 不能反向推出 I16。

因此严格更强正例存在具体反例状态，证明不变量确实包含目标条件未约束的信息。比较作用域是已建模的目标验证条件，而不是忽略控制流的原始断言字符串。

## 一个可直接解释的 exact 示例

linear_2 的循环从 x=1、y=0 开始，每轮执行 x=x+y、y=y+1，条件为 y<1000。最终子句等价于：

0 <= y <= 1000 AND x = 1 + y*(y-1)/2。

每个整数 y=t（0<=t<=1000）恰好对应执行 t 轮后的状态，因此这是该程序的精确循环头可达集合。退出时它给出 y=1000、x=499501，严格强于原隐藏目标 x>=y。

## 对 rebuttal 的意义

可用来支持“生成的摘要包含原目标之外的信息”，并在已认证 exact 的程序上支持“在所建模状态空间中保留了全部循环头可达性信息”。这比个例提供了更系统的语义证据。

本分析没有新增独立指定的 held-out goals，也没有比较目标可见与目标隐藏生成的复用率；不能据此宣称隐藏目标本身使摘要更可复用。
